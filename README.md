📌 Project Overview

This project provides an end-to-end data analytics study of 5,000 hospital patient records to understand patient care patterns, hospital resource utilization, length of stay, disease severity, and 30-day readmission.

The primary objective is to analyze hospital operations and identify patterns that can support better resource planning, patient care, and operational efficiency.

🎯 Project Objectives

* Patient Admission Analysis: Analyze admission patterns across departments and admission types.
* Resource Utilization: Examine bed and ICU utilization.
* Length of Stay: Analyze patient length of stay across departments and severity levels.
* Disease Severity: Study patient distribution by severity.
* Readmission Analysis: Examine 30-day readmission patterns.

📊 Analytical Roadmap & Highlights

1. Data Understanding

* Dataset structure, rows and columns
* Data types and categorical variables
* Missing values and duplicates

2. Data Preprocessing

* Missing-value handling
* Duplicate checking
* Data-type conversion
* Outlier detection and handling

3. Exploratory Data Analysis

* Patient demographics
* Admission patterns
* Department-wise analysis
* Length of stay
* Bed and ICU utilization
* 30-day readmission

4. Feature Engineering

* Length of Stay Category
* Bed Occupancy Rate
* ICU Occupancy Rate

5. Business Insights

* Identify departments with higher resource utilization
* Understand factors associated with longer hospital stays
* Analyze readmission patterns
* Support hospital resource planning
